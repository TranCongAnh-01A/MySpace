## Phiên C — Phase C1: Design system + vỏ ứng dụng (v0.1)

### Tóm tắt công việc

> `feat(ui)` C1 design system + vỏ ứng dụng + Settings

- Token Dark/Light (`src/styles/tokens.css`), font Inter đóng gói, theme `data-theme` + script chạy sớm (cache `lifehub.theme`), theo Windows khi chọn `System`.
- `src/lib/ipc/contract.ts` (kiểu tạm theo hợp đồng B1 mục 2.1), wrapper mọi command v0.1 trong `commands.ts`, `mock.ts` đủ command (trễ 150 ms, `Alt+F4` → `CONFLICT`, restore → reload), `src/lib/tauri.ts` bọc API Tauri để chạy được trong trình duyệt.
- i18n vi/en tự viết (`en` bắt buộc đủ khoá), định dạng ngày theo `dateFormat` (có test).
- Component nền (`src/components/ui/`): Button, Input/Textarea, Label, Switch, Select, Combobox, Dialog/AlertDialog, DropdownMenu/ContextMenu, Tabs, Card, Toast (sonner), Badge, Skeleton, EmptyState/ErrorState, DatePicker, Tooltip, Kbd.
- Vỏ app: TitleBar (kéo cửa sổ, ô tìm kiếm chỉ hiển thị, "Thêm nhanh", 3 nút cửa sổ), Sidebar thu gọn (Zustand persist `lifehub.ui`; chỉ Inbox + Settings), router `/inbox`, `/settings/:tab?`, phím tắt `Ctrl+2`, `Ctrl+,`, `Ctrl+Q`, skip link.
- Settings 5 tab: Chung, Phím tắt & hệ thống (ô ghi phím), Thông báo, Lĩnh vực (dnd-kit chuột + bàn phím), Dữ liệu (thư mục, sao lưu, khôi phục, xuất JSON).
- Inbox + Quick Capture đổi sang token/component mới; Inbox có empty state, menu chuột phải (Xoá: "Sắp có").
- `useEntityChangedInvalidation()` gắn ở gốc app; đổi settings dùng optimistic update + rollback + toast.
