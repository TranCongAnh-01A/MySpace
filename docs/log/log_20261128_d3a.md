Môi trường: msedgedriver tự đặt `WEBVIEW2_USER_DATA_FOLDER` thành `C:\Windows\SystemTemp\scoped_dir…` và `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS` có `--remote-debugging-port=0`. Sau 60 s driver báo `DevToolsActivePort file doesn't exist`.

Chẩn đoán thụ động sau 20 s: thư mục `…\EBWebView` đã có đủ hồ sơ (Default, Crashpad, GPUPersistentCache…) nhưng **không có file `DevToolsActivePort`**. Vậy WebView2 chạy và dùng đúng thư mục nhưng không mở cổng gỡ lỗi, hoặc không ghi file.
